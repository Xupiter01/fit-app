# 🏋️ Fit - Smart Workout Planner & Progressive Overload Engine

แอปพลิเคชันเว็บระดับพรีเมียมสำหรับช่วยออกแบบ **Workout Plan** อัจฉริยะ รองรับโปรแกรมยอดนิยมระดับโลกอย่าง **Push Pull Legs (PPL)** พร้อมระบบแนะนำน้ำหนักตามหลักการ **Progressive Overload** และกายวิภาคกล้ามเนื้อพร้อมภาพประกอบและเทคนิคครบถ้วน

---

## 🚀 วิธีเปิดใช้งานแอปพลิเคชัน

### วิธีที่ 1: ดับเบิ้ลคลิกเปิดใช้งานทันที (แนะนำ)
- ดับเบิ้ลคลิกที่ไฟล์ **`start.bat`** หรือดับเบิ้ลคลิกไฟล์ **`index.html`** เพื่อเปิดใช้งานบนเบราว์เซอร์ (Chrome, Edge, Firefox, Safari) ทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริมใดๆ

### วิธีที่ 2: รันผ่าน Local Server (PowerShell)
คลิกขวาที่ไฟล์ `serve.ps1` แล้วเลือก **Run with PowerShell** หรือเปิดเทอร์มินัลแล้วพิมพ์:
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```
ระบบจะเปิดเว็บเซิร์ฟเวอร์ที่ `http://localhost:5055/` และเปิดเบราว์เซอร์ให้อัตโนมัติ

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. 🏋️ แผนการฝึก Push Pull Legs (PPL) และการปรับแต่ง (Workout Plans)
- **Push Pull Legs (PPL) - 3 วัน / สัปดาห์**: รูปแบบมาตรฐาน เหมาะสำหรับทุกคนที่มีเวลาออกกำลังกาย 3 วันต่อสัปดาห์
  - **Push Day**: หน้าอก (Chest), หัวไหล่ (Shoulders), หลังแขน (Triceps)
  - **Pull Day**: แผ่นหลัง (Back), ปีก (Lats), หน้าแขน (Biceps)
  - **Legs & Core Day**: ต้นขาด้านหน้า (Quads), ต้นขาด้านหลัง (Hamstrings), บั้นท้าย (Glutes), น่อง (Calves), หน้าท้อง (Core)
- **Push Pull Legs (PPL) - 6 วัน (Hypertrophy Pro)**: สำหรับผู้มีประสบการณ์ เน้นความถี่ 2 ครั้งต่อสัปดาห์ (Frequency 2x)
- **Upper / Lower Split - 4 วัน**: สำหรับผู้ที่ต้องการสมดุลเวลาและการพักผ่อน
- **Plan Customizer**: สามารถกด **"✏️ ปรับแต่งท่าฝึกในวันนี้"** เพื่อเพิ่ม/ลบท่าฝึก ปรับเซ็ต และเปลี่ยนจำนวนครั้งได้ตามต้องการ หรือกด **"+ ออกแบบแผนใหม่"** ได้อย่างอิสระ

### 2. 🎯 ระบบเลือกเป้าหมาย & บริหารน้ำหนักอัตโนมัติ (Progressive Overload Engine)
- **เลือกระบบเป้าหมายได้ 4 มิติ**:
  1. **สร้างกล้ามเนื้อ (Muscle Hypertrophy)**: 8-12 ครั้ง, ความเข้มข้น 65-75% 1RM, พัก 60-90 วินาที
  2. **เพิ่มพละกำลัง (Max Strength)**: 3-6 ครั้ง, ความเข้มข้น 80-90% 1RM, พัก 2-3 นาที
  3. **ลดไขมัน & กระชับสัดส่วน (Fat Loss)**: 12-15+ ครั้ง, ความเข้มข้น 55-65% 1RM, พัก 30-60 วินาที
  4. **ผู้เริ่มต้น (Beginner Foundation)**: 10-12 ครั้ง, โฟกัสฟอร์มถูกต้อง 100%
- **ระบบคำนวณ Progressive Overload อัตโนมัติ**:
  - วิเคราะห์ประวัติเซสชันก่อนหน้า และค่า RPE (Rate of Perceived Exertion)
  - หากทำครบตามเป้าหมายสูงสุดด้วย RPE สบาย ระบบจะแนะนำปรับเพิ่มน้ำหนัก **+2.5 กก.** (ท่าท่อนบน) หรือ **+5.0 กก.** (ท่าท่อนล่าง)
  - หากประเมินว่าล้าเกินไปหรือฟอร์มตก ระบบจะแนะนำคงน้ำหนักหรือลดลงเล็กน้อย (Deload) เพื่อความปลอดภัย
- **เครื่องคำนวณ 1RM (One Rep Max)**: คำนวณจากสูตรผสม Epley & Brzycki พร้อมคำนวณน้ำหนัก Working Set สำหรับเป้าหมาย
- **ปุ่มบันทึกเกณฑ์ & การปรับแผนทั้งหมด (Save Baseline & Plan Sync)**:
  - ใส่ท่าออกกำลังกาย + น้ำหนัก + จำนวนครั้ง จากนั้นกด **💾 บันทึกเกณฑ์ & ปรับแผนทั้งหมด**
  - ระบบจะแสดงตาราง **ผลการปรับแผน** ทันที โดยเทียบน้ำหนักเดิมกับน้ำหนักที่เสนอ ของทุกท่าในแผนที่เลือกได้ เช่น บันทึก Barbell Bench Press แล้วระบบจะคำนวณว่า Lat Pulldown / Squat / Deadlift ควรเป็นเท่าไหร่
  - **ปรับอัตโนมัติตามสัดส่วนจริงของผู้ใช้เอง (Personalized Ratio)**: ท่าที่ยังไม่มีข้อมูลจะไม่ใช้ค่ามาตรฐานตายตัว แต่จะคำนวณจาก 1RM จริงที่คุณเคยบันทึก โดยเทียบกับท่าที่ “คล้ายกัน” (กลุ่มกล้ามเนื้อ, ชนิดท่า, อุปกรณ์) — เช่น คุณสควอท/เดดลิฟต์ได้ต่ำกว่าสัดส่วนมาตรฐานเมื่อเทียบกับเบนช์เพรส ระบบก็จะลดน้ำหนักของท่าขาที่ยังไม่เคยบันทึกลงตามสัดส่วนเดียวกัน
  - ระบบป้องกันค่าผิดปกติด้วย *winsorizing* และจำกัดอิทธิพลของแต่ละท่าที่ใช้อ้างอิง (ไม่เกิน 45%) เพื่อไม่ให้ข้อมูลผิดพลาดครั้งเดียวทำแผนเพี้ยน
  - ในตารางจะระบุที่มาของแต่ละตัวเลขเสมอ เช่น **สัดส่วนจริงของคุณ**, **สัดส่วนของคุณ** (ปรับจากท่าที่บันทึกคล้ายกัน), **ผสมสัดส่วนของคุณ** หรือ **เกณฑ์มาตรฐาน**
  - **ปรับมือรายท่า (Manual Lock)**: กด **⚙️ ตั้งเอง** ในคอลัมน์ “ปรับมือ” เพื่อล็อกน้ำหนักที่คุณต้องการด้วยตัวเอง ระบบจะไม่แก้ไขค่านั้นแม้กดบันทึกใหม่ก็ตาม จนกว่าจะกด **🔓 ปลดล็อก** (ลำดับความสำคัญ: ค่าที่คุณตั้งเอง > ข้อมูลที่บันทึกจริง > สัดส่วนของคุณ > เกณฑ์มาตรฐาน)
- **ปิดวงจรการเรียนรู้ (Learning Loop)**: ทุกครั้งที่กด “สรุปและบันทึก” ระบบจะแสดงว่าเพิ่งเรียนรู้อะไรจากเซสชันนั้น (ท่าไหน น้ำหนักเท่าไร 1RM เท่าไร) และนำไปเป็นสัดส่วนส่วนตัวทันที พร้อมแสดงวันที่อัปเดตล่าสุดในหน้าเป้าหมาย
  - **ท่าที่ยังไม่เคยบันทึกน้ำหนักเลย** จะได้รับเกณฑ์นี้เป็นค่าเริ่มต้นทันที (ถ้ายังไม่มีข้อมูลในเลย ค่าที่กรอกครั้งแรกคือ “บันทึกครั้งแรก” ของท่านั้น)
  - **ท่าที่บันทึกการออกกำลังกายจริงแล้ว** จะยึดข้อมูลจริงเป็นหลักเสมอ และแสดงป้าย “ยึดข้อมูลจริง” โดยไม่ถูกเกณฑ์ที่คำนวณทับ
  - มีปุ่ม **↩️ ย้อนกลับค่าก่อนหน้า** หากบันทึกผิด
  - ผลลัพธ์ถูกใช้ต่อทันทีในหน้าแผนฝึก (ป้าย ⚖️ ข้างทุกท่า) และในหน้าเริ่มออกกำลังกาย (น้ำหนักเริ่มต้นของแต่ละเซ็ต)
- **เครื่องคำนวณเซ็ตวอร์มอัพ (Warm-Up Sets) & การใส่แผ่นบาร์เบล**: แสดงขั้นตอนการวอร์มและจำนวนแผ่นน้ำหนักที่ต้องใส่ข้างละกี่กิโลกรัมอย่างละเอียด

### 3. 📖 ภาพประกอบ & กายวิภาคกล้ามเนื้อ & เทคนิคแต่ละท่า (Exercise Library)
- **ภาพประกอบชีวกลศาสตร์ (SVG Biomechanical Diagrams)**: แสดงวิถีการเคลื่อนไหว มุมข้อศอก และตำแหน่งที่ถูกต้อง
- **แผนที่กายวิภาคกล้ามเนื้อ (Anatomical Muscle Map)**: แสดงไฮไลต์สีเขียว (กล้ามเนื้อมัดหลัก) และสีม่วง (กล้ามเนื้อช่วยเสริม) ทั้งด้านหน้าและด้านหลัง
- **เทคนิคการเล่นแบบจับมือทำ**:
  - **Setup**: การจัดระเบียบร่างกาย ท่าเริ่มต้น การวางเท้า การหนีบสะบัก
  - **Execution**: ลำดับการเคลื่อนไหว การควบคุมความเร็ว (Tempo)
  - **Breathing**: จังหวะการหายใจที่ถูกต้อง (Valsalva Maneuver)
  - **Common Mistakes**: ข้อผิดพลาดที่พบบ่อยและวิธีแก้ไขเพื่อไม่ให้บาดเจ็บ
  - **Pro Tips**: เคล็ดลับขั้นสูง เช่น Mind-Muscle Connection และ Leg Drive

### 4. ⚡ ระบบบันทึกข้อมูลขณะออกกำลังกาย (Live Workout Tracker)
- **จับเวลาเซสชัน (Workout Duration)** แบบเรียลไทม์
- **Rest Timer อัจฉริยะ**: จับเวลาพักระหว่างเซ็ต พร้อมเสียงสัญญาณเตือนสังเคราะห์ผ่าน Web Audio API เมื่อพักครบ
- **บันทึกละเอียด**: บันทึกน้ำหนัก (กก.), จำนวนครั้ง (Reps), และ RPE ในแต่ละเซ็ต พร้อมปุ่มทำเครื่องหมายสำเร็จ (✓)
- **คำนวณ Volume สะสมสด**: แสดงน้ำหนักรวมที่ยกได้ในเซสชันแบบเรียลไทม์
- **ตัวนับเซ็ตคงเหลือ (🎯)**: แสดงว่าเหลืออีกกี่เซ็ตทั้งเซสชัน ลดลงทุกครั้งที่ติ๊กสำเร็จ

### 4.1 📱 โหมดมือถือ "ระหว่างเซ็ต" (Between-Sets Quick Tools)
ออกแบบมาเพื่อใช้ในยิมโดยไม่ต้องปลดล็อกมือถือหรือเลื่อนหาตาราง — แถบเครื่องมือแบบ sticky อยู่ใต้ทุกท่าออกกำลังกาย

- **🔁 ซ้ำเซ็ตก่อน**: คัดลอกน้ำหนัก/จำนวนครั้ง/RPE จากเซ็ตล่าสุดที่ทำสำเร็จ ไปใส่ทุกเซ็ตที่ยังไม่สำเร็จ (ถ้ายังไม่มีเซ็ตไหนสำเร็จ จะใช้ค่าของเซ็ตที่มีน้ำหนักแทน)
- **Weight stepper (−2.5 / −1 / +1 / +2.5)**: ปรับน้ำหนักของเซ็ตที่กำลังจะทำโดยไม่ต้องพิมพ์ ลดเป็นทศนิยมครึ่งกิโลกรัมเสมอ
- **⤴ คัดลอกเซ็ตเดียว**: คัดลอกค่าของเซ็ตนั้นไปยังเซ็ตถัดไปที่ยังไม่สำเร็จ
- **Double Progression อัตโนมัติ**: ติ๊กเซ็ตสำเร็จแล้ว เซ็ตถัดไปจะถูกเตรียมให้เท่ากับเซ็ตที่เพิ่งทำสำเร็จทันที
- **เน้นเซ็ตเป้าหมาย**: แถวเซ็ตที่กำลังจะทำถูกไฮไลต์ด้วยเส้นสีฟ้า และแถบ sticky แสดง "เซ็ต 2 / 4 · เหลือ 2 เซ็ต"
- **ป้องกันการทับ**: คำนวณความสูง header/nav/session bar จริงเป็น CSS variable (`--app-header-h`, `--session-bar-h`, `--bottom-nav-h`) แล้วยิง offset ให้แถบ sticky กับเนื้อหาท้ายหน้า เพื่อไม่ให้ปุ่มถูกเมนูล่างหรือ header บังจนกดไม่โดน

### 4.2 🌙 โหมดโค้ดหน้าจอสำหรับยิม (Gym Screen Dimmer)
เปิด/ปิดด้วยปุ่มเดียว (🌙) ในแถบเซสชัน — สำหรับยิมที่มืด เพื่อไม่ให้แสงจอจ้าทำลายสายตากลางคืน และกันหน้าจอดับระหว่างพัก

- **กันหน้าจอดับ (Screen Wake Lock API)**: ขอสิทธิ์ไม่ให้จอเข้าสลีปขณะโหมดเปิด และขอใหม่อัตโนมัติเมื่อสลับแท็บกลับมา พร้อมสถานะแจ้งว่าได้สิทธิ์แล้วหรือยัง (รองรับเบราว์เซอร์ที่ไม่รองรับ — โหมดโค้ดยังทำงานปกติ)
- **3 ระดับความมืด**: ต่ำ / กลาง / สูง เลือกจาก HUD ได้ทันที และจำค่าไว้
- **แตะเพื่อดูชั่วคราว (Peek)**: แตะที่หน้าจอมืดเมื่อไรก็ได้ จะสว่างกลับมา 8 วินาที แล้วคืนความมืดให้เอง (ถ้าขอ Wake Lock ไม่สำเร็จครั้งแรก จะลองใหม่ตอนแตะ)
- **HUD ลอยเหนือความมืด**: นาฬิกานับถอยหลังขนาดใหญ่ + ชื่อท่าที่กำลังจะทำ + เซ็ตที่เหลือ อ่านได้โดยไม่ต้องแตะจอ พร้อมแถบความคืบหน้า
- **ค๊อดลึกขึ้นตอนพัก**: ระหว่างที่ rest timer กำลังเดิน หน้าจอจะเข้มขึ้นอีก 10% อัตโนมัติ
- **ปิดอัตโนมัติเมื่อจบ/ยกเลิก**: ปล่อย Wake Lock และปิดโหมดอัตโนมัติเมื่อสรุปเซสชันหรือกดยกเลิก
- ตั้งค่าถูกจำไว้ใน `fit_dimmer_v1`

## 📱 เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5 & CSS3**: ดีไซน์ธีม Dark Mode สไตล์โมเดิร์น ยืดหยุ่นทั้งบนมือถือ (Mobile-First) และเดสก์ท็อป
  - **ออกแบบมาสำหรับการใช้งานในยิมด้วยมือถือเป็นหลัก**: ขนาดตัวอักษร 16px ขึ้นไป, ปุ่ม/ช่องกรอกสูงอย่างน้อย 48px, ไม่ให้ iOS ซูมเข้าเวลาแตะช่องกรอก
  - **ตารางข้อมูลกลายเป็นการ์ดแนวตั้ง** บนมือถือ (ตารางผลการปรับแผน และตารางบันทึกเซ็ต) พร้อมป้ายกำกับแต่ละช่อง อ่านง่ายกว่าตารางที่ต้องเลื่อนซ้าย-ขวา
  - **บันทึกการออกกำลังกายแบบย่อ**: แต่ละเซ็ตเป็นการ์ด 2 คอลัมน์ (น้ำหนัก/จำนวนครั้ง, RPE/ปุ่มสำเร็จ) กดง่ายแม้มือเปียกหรือถือดัมเบลล์
  - รองรับ `safe-area-inset` ของ iPhone (แถบเมนูล่างและระยะขอบล่าง)
- **Vanilla JavaScript (ES6+)**: ประสิทธิภาพสูง โหลดเร็วทันใจ ไม่มี Dependencies ภายนอก
- **Web Audio API**: สร้างเสียงสัญญาณเตือนนับถอยหลังโดยไม่ต้องพึ่งพาไฟล์เสียงภายนอก
- **LocalStorage**: บันทึกข้อมูลถาวรในเครื่องของผู้ใช้งาน 100% ปลอดภัยและเป็นส่วนตัว
  - คีย์หลัก: `fit_user_profile_v1`, `fit_plans_v1`, `fit_workout_history_v1`, `fit_active_workout_v1`, `fit_personal_records_v1`, `fit_exercise_baselines_v1` (เกณฑ์น้ำหนักต่อท่าที่บันทึกจากเครื่องคำนวณ) และ `fit_dimmer_v1` (ค่าตั้งโหมดโค้ดหน้าจอ)
- **Screen Wake Lock API**: กันหน้าจอดับระหว่างโหมดโค้ดหน้าจอสำหรับยิม (มี fallback และแจ้งสถานะเมื่อเบราว์เซอร์ไม่รองรับ)
